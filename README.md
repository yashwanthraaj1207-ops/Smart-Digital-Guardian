# Smart-Digital-Guardian
Smart Digital Guardian is an AI-powered cybersecurity web application designed to protect students from phishing links, scam messages, and malicious online threats. The system uses Machine Learning techniques to analyze text and detect potential cyber risks in real time.

🚀 Features

Phishing link detection using AI

Scam and malicious message detection

Real-time threat analysis

User-friendly web interface

Cybersecurity awareness support

🧠 Technologies Used

Python

Streamlit

Scikit-learn

TF-IDF Vectorizer

Logistic Regression

🎯 Purpose

To create a smart and accessible cybersecurity assistant that helps students identify and avoid online threats using Artificial Intelligence.
